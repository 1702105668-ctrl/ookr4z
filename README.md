# 摸鱼小站 🐟

一个纯静态的个人小站：不需要服务器、不需要数据库、不需要安装任何东西。
把文件夹里的文件传到 GitHub，再打开 GitHub Pages，就能得到一个公开网址。

## 里面有什么

| 按钮 | 内容 |
| --- | --- |
| 🎼 打歌 | 原创的 Phigros 风格 4K 节奏小游戏，键盘 D F J K 或手机触屏 |
| 🎧 听歌 | 网页现场合成的轻音乐 + 播放你电脑里的 MP3/WAV（不会上传） |
| 💣 扫雷 | 初级 9×9、中级 16×16、高级 16×30，第一步不会踩雷 |
| 📺 看 B 站 | 粘贴 BV 号 / 视频链接，用 B 站官方播放器站内播放 |
| 📝 随手记 | 自动保存到浏览器本地的小便签 |

> 说明：打歌是「Phigros 风格」的原创小游戏，不是 Phigros 游戏本体。
> B 站视频能否站内播放，取决于 UP 主是否允许嵌入；不能播时点「去 B 站打开」即可。

## 文件都是干什么的

```
my-site/
├─ index.html       网页的骨架（一般不用改）
├─ style.css        颜色、布局、动画（想换主题色再改）
├─ config.js        ★ 最常改：名字、头像、简介、GitHub 链接
├─ app.js           首页导航、便签、B 站、迷你播放条
├─ rhythm.js        打歌小游戏
├─ music.js         听歌功能
├─ minesweeper.js   扫雷
├─ README.md        本文件
└─ 部署教程.md      ★ 从零上传 GitHub 的超详细步骤
```

## 先在本机看看

直接双击 `index.html` 就能打开。

- 打歌、扫雷、便签、内置轻音乐都可以直接用。
- 「看 B 站」在 `file://` 直接打开时可能被浏览器跨域策略拦住，部署到 GitHub 后就正常了。
- 本地音乐需要你在页面里手动选择电脑上的文件。

## 改成你自己的

用记事本或 VS Code 打开 `config.js`，改这几行：

```js
window.SITE_CONFIG = {
  name: "摸鱼小站",          // 网站名字
  owner: "站长",             // 你的昵称
  avatar: "🐟",              // 头像 emoji，比如 "🐱" "🌙" "🍜"
  bio: "白天认真生活……",     // 一句话介绍
  github: "",                // 你的 GitHub 主页，没有就留空
  footer: "用 ❤️ 和一点点代码搭成 · Hosted on GitHub Pages"
};
```

改完保存，再按 `部署教程.md` 上传即可。

想换主题色，打开 `style.css`，改最上面 `:root` 里的
`--pink`、`--purple`、`--teal`、`--yellow`、`--blue` 几个颜色。

## 发布到 GitHub Pages

请看 **[部署教程.md](部署教程.md)**，里面是从注册 GitHub 开始的大白话步骤。

简单说就四步：

1. 在 GitHub 新建一个 **Public** 仓库；
2. 把本文件夹里的文件全部上传（`index.html` 必须在仓库最外层）；
3. 在 Settings → Pages 里选择 `main` 分支 + `/ (root)`，保存；
4. 等 1–3 分钟，打开 GitHub 给你的网址。

## 隐私提醒

- GitHub Pages 是公开网站，**不要**把真实姓名、电话、住址、密码、身份证照片放上来。
- 便签只保存在你自己的浏览器里，不会上传，也不会同步到别的设备。
- 本地音乐只在浏览器里播放，不会上传到 GitHub。
- B 站视频版权归原作者，本站只是使用 B 站官方播放器嵌入。

## 常见问题

**为什么打不开真正的 Phigros？**
Phigros 是手机游戏，不能直接塞进网页。这里做的是一个同风格的四键节奏小游戏，玩法相似，曲子是网页现场合成的原创旋律。

**为什么 B 站视频是空白？**
有些 UP 主关闭了“允许嵌入”。点视频下方的「去 B 站打开」即可。也可能是网络较慢，等一会儿或刷新看看。

**为什么笔记换电脑就没了？**
便签存在浏览器的 `localStorage` 里，只属于当前浏览器。换设备、换浏览器或清除网站数据都会丢。

**GitHub 打开很慢怎么办？**
GitHub 在国内有时会慢，可以多刷新几次、换个网络，或者早上人少的时候操作。网站本身通常能正常访问。
