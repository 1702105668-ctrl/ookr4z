# OoKr4z 的小站 🐟

一个纯静态的个人小站：不需要服务器、不需要数据库、不需要安装任何东西。
主要功能是 **4K 打歌**、**网易云歌单** 和 **扫雷**。

## 里面有什么

### 🎼 打歌

- **20 张 4K 谱面**：
  - Jack 8 张（Reg-3 → Reg-10）
  - Stream 8 张（Reg-3 → Reg-10，Stream 中文叫“切键”）
  - LN 4 张：Kisaragi / Nastrond / Twin Bloom（Aestivation、Ramification）
- 使用你提供的 **OoKr4z's skin**：
  - note、长条、按键、判定线 hint、舞台角色都来自这套皮肤；
  - 没有给 note 加额外染色，保留皮肤原色。
- 选曲界面：左侧谱面列表，右侧谱面信息（曲绘、歌名、曲师、谱师、星数、历史最高分、开始按钮）。
- 游戏内设置：
  - **流速**：osu!mania 原生 1–40 滑条，默认 30；
  - **音量**：0–100；
  - **OD**：0–10 滑条，判定窗口按 osu!mania 公式；
  - **偏移**：−100 ~ +100 ms；
  - **AP / FC 标**显示开关。
- 判定：Perfect / Great / Good / Bad / Miss，长条需要按住。
- 电脑按 `D F J K` 或方向键；手机点下方四个按键。
- 最高分存在浏览器里，不跨设备同步。

### 🎧 听歌

- 你自己的网易云歌单 **This is true music**，完整 **43 首**。
- 之前官方“歌单外链播放器”只显示前 10 首；新版改成：
  - 左侧完整 43 首列表（可搜索歌名 / 曲师）；
  - 右侧大封面、歌名、曲师、专辑；
  - 点任意一首，右下角官方单曲播放器自动播放。
- 没有“在网易云打开”按钮。
- 歌单由网易云官方播放器提供，版权 / 会员限制以网易云提示为准。

### 💣 扫雷

经典三档难度：初级 9×9、中级 16×16、高级 16×30。
第一步永远不会踩雷，支持右键 / 长按插旗。

## 文件都是干什么的

所有文件都在**同一层**，没有子文件夹，方便 GitHub 网页上传。

| 文件 | 作用 |
| --- | --- |
| `index.html` | 网页骨架 |
| `style.css` | 颜色、布局、动画 |
| `config.js` | ★ 最常改：名字、头像、简介、GitHub 链接 |
| `app.js` | 首页导航、时钟、路由 |
| `rhythm.js` | 4K 打歌引擎、设置、判定 |
| `music.js` | 网易云完整歌单 UI |
| `minesweeper.js` | 扫雷 |
| `songs-data.js` | 20 张谱面的歌曲信息 |
| `charts-data.js` | 20 张谱面的音符数据 |
| `playlist-data.js` | 歌单 43 首的歌名 / 曲师 / 封面 |
| `audio-*.mp3` | 19 个音频文件（20 张谱面，Twin Bloom 两个难度共用一首） |
| `cover-*.webp` | 封面 |
| `skin-*` | OoKr4z's skin 里用到的 note、长条、按键、判定线、角色图 |
| `README.md` | 本文件 |
| `部署教程.md` | ★ 从零上传 GitHub 的大白话步骤 |

> 文件合计 **58 个、约 50 MB**。不要改 `audio-*`、`cover-*`、`skin-*`、`songs-data.js`、`charts-data.js` 这些名字，改完网页会找不到资源。

## 先在本机看看

直接双击 `index.html` 即可。

- 打歌、扫雷、选曲界面都能直接用。
- 网易云播放器在本地 `file://` 预览时可能被浏览器拦截，部署到 GitHub 后就正常。
- 第一次进入某张谱面会加载几 MB 音频，等一两秒正常。

## 改成你自己的

用记事本或 VS Code 打开 `config.js`：

```js
window.SITE_CONFIG = {
  name: "OoKr4z的小站",
  owner: "OoKr4z",
  avatar: "🐟",
  bio: "Once Forgotten,Nothing Remains",
  github: ""
};
```

改完保存，再按 [部署教程.md](部署教程.md) 上传。

## 发布到 GitHub Pages

完整步骤看 **[部署教程.md](部署教程.md)**。简单说：

1. 打开原仓库，点 **Add file → Upload files**；
2. 打开 `my-site` 文件夹，`Ctrl + A` 全选**所有文件**，拖进浏览器；
3. 点 **Commit changes**；
4. 等 1–3 分钟，打开原网址，按 `Ctrl + F5`。

因为这次是 58 个文件、约 50 MB，网页上传会比较慢。**建议用 GitHub Desktop**，或者分 3 批上传：

1. 代码 + 数据 + 文档 + 皮肤；
2. 19 个 `audio-*.mp3`；
3. 19 张 `cover-*.webp`。
