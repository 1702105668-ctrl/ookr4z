# OoKr4z 的小站 🐟

一个纯静态的个人小站：不需要服务器、不需要数据库、不需要安装任何东西。
主要功能是 **4K 打歌**、**网易云歌单** 和 **扫雷**。

## 里面有什么

### 🎼 打歌

- 16 张 4K 谱面，来自你给的两个 Malody 4K Regular Dan v3（Jack / Stream）。
- 使用你提供的 **OoKr4z's skin**：note、长条、按键、舞台角色都来自这套皮肤。
- 点「打歌」先进入选曲界面：可以切换 JACK / STREAM，点封面看详情，再开始。
- 支持长条按住、Perfect / Great / Good / Bad / Miss、COMBO、准确率、结算和最高分。
- 电脑按 `D F J K` 或方向键；手机点下方四个按键。
- 音符速度可选：慢 / 标准 / 快 / 极快。
- 已经去掉两个 osz 里的 `delete upon download` 占位谱面（也就是你说的 delete plz）。
- 打歌时会自动关掉网易云播放器，避免两首歌叠在一起。

### 🎧 听歌

- 直接嵌入你的网易云公开歌单：`12374407187`。
- 播放器、歌曲封面、歌名、播放控制都是网易云官方外链提供的。
- 点播放器里的歌就能听；部分歌可能受版权 / 会员限制。
- 离开听歌页面后播放器可能继续播放，回到页面可以继续控制。

### 💣 扫雷

经典三档难度：初级 9×9、中级 16×16、高级 16×30。
第一步永远不会踩雷，支持右键 / 长按插旗。

## 文件都是干什么的

所有文件都在**同一层**，没有子文件夹，方便 GitHub 网页上传。

| 文件 | 作用 |
| --- | --- |
| `index.html` | 网页骨架 |
| `style.css` | 颜色、布局、动画 |
| `config.js` | ★ 最常改：名字、头像、简介、GitHub 链接 |
| `app.js` | 首页导航、时钟、路由 |
| `rhythm.js` | 4K 打歌引擎 |
| `music.js` | 网易云播放器的懒加载 |
| `minesweeper.js` | 扫雷 |
| `songs-data.js` | 16 张谱面的歌曲信息 |
| `charts-data.js` | 16 张谱面的音符数据 |
| `audio-*.mp3` | 16 首歌的音频（已裁掉过长前奏/尾奏） |
| `cover-*.webp` | 16 张封面 |
| `skin-*` | OoKr4z's skin 里用到的 note、长条、按键、角色图 |
| `README.md` | 本文件 |
| `部署教程.md` | ★ 从零上传 GitHub 的大白话步骤 |

> 这些文件加起来大约 **32 MB**。不要改名，尤其是 `audio-*`、`cover-*`、`skin-*` 和两个 `*-data.js`，改名后网页会找不到。

## 先在本机看看

直接双击 `index.html` 即可。

- 打歌、扫雷、选曲界面都能直接用。
- 网易云播放器在本地 `file://` 预览时可能被浏览器跨域策略拦住，部署到 GitHub 后就正常。
- 打歌音频第一次点击会加载 1–3 MB，等一两秒是正常的。

## 改成你自己的

用记事本或 VS Code 打开 `config.js`：

```js
window.SITE_CONFIG = {
  name: "OoKr4z的小站",          // 网站名字
  owner: "OoKr4z",               // 昵称
  avatar: "🐟",                  // 头像 emoji
  bio: "Once Forgotten,Nothing Remains",
  github: "",                    // 你的 GitHub 主页，没有就留空
  footer: "OoKr4z · ..."
};
```

改完保存，再按 `部署教程.md` 上传。

## 发布到 GitHub Pages

完整步骤看 **[部署教程.md](部署教程.md)**。简单说：

1. 在 GitHub 仓库里点 **Add file → Upload files**；
2. 打开 `my-site` 文件夹，`Ctrl + A` 全选**所有文件**，拖进浏览器；
3. 点 **Commit changes**，等 1–2 分钟；
4. 打开 `https://你的用户名.github.io/my-site/`。

因为这次是 49 个文件、约 32 MB，网页上传会需要几分钟，耐心等进度条走完。

## 常见问题

**为什么打歌第一次点开始要等？**
谱面数据和音频是按需加载的，第一次会读取 `charts-data.js` 和对应的 `audio-*.mp3`，之后就快了。

**为什么某首歌没有声音？**
先点一下页面里的开始按钮（浏览器不允许网页自动出声），再检查音量。iPhone 要关掉侧边静音开关。

**为什么网易云有歌放不了？**
版权或会员限制，官方播放器会提示；可以点「在网易云打开」。

**为什么最高分换设备就没了？**
最高分存在浏览器 `localStorage` 里，只属于当前浏览器。

**GitHub 上传很慢怎么办？**
32 MB 用网页上传确实会慢。可以改用 GitHub Desktop：把仓库克隆到电脑，替换文件后 Commit → Push，会稳很多。
